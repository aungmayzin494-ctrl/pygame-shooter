# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

> 이 README 는 스타터에 들어 있던 것입니다. 제출 전에 아래 **[학생 작성]** 부분을 직접 채우세요.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |
| `settings.py` | 화면 크기·속도·색 같은 상수 |
| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |

## 구현한 기능 

<!-- 구현한 기능을 확인할 것. 예: - [x] F1 플레이어 이동 — 방향키 좌우 이동, 화면 밖으로 나가지 않음 -->

- [x] F1 플레이어 이동 - 왼쪽/오른쪽 방향키로 비행기가 이동, 화면 밖으로 나가지 않음
- [x] F2 총알 발사 - SPACE 키를 누르면 비행기 위쪽 가운데에서 총알이 나가 위로 날아감, 화면 밖으로 나가면 사라짐
- [x] F3 적 명중과 점수 - 총알이 적에 맞으면 적과 총알이 함께 사라짐, 적 한 개당 10점이 오름, SCORE는 왼쪽 위에 표시됨
- [x] F4 피격과 게임 오버 - 적이 player에 닿거나 화면 아래로 지나가면 life 줄임, 생명이 0 이 되면 GAME OVER 와 이번 판 점수 화면에 표심및 멈춤
- [x] F5 재시작과 최고 점수 - 게임 오버에서 R 키로 새판 시작, 최고 점수는 highscore.txt 에 저장되어 게임을 끄고 다시 실행해도 이전 최고 점수 보여줌, 최고 점수(HIGH SCORE: 300)와 제시작 안내(Press R to restart) 화면에 표시함.
